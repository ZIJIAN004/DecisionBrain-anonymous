The output file must be a JSON object containing only the following fields:

- formulation_type: "lp" or "milp"
- variables: every variable, including its type, lower and upper bounds, indices, and business meaning
- parameters: input parameters and their sources
- constraints: every hard constraint, including index ranges, linear expressions, and business meaning
- objective: direction, expression, and objective meaning
- data_mapping: the complete mapping from input data to model parameters
- solution_mapping: the complete mapping from model variables to solution_schema.json
- completeness_checklist: item-by-item confirmation that every business rule is covered

This is a complete model definition, not code. Do not write package/source fields, declare a generated algorithm, or add a heuristic, warm_start, decomposition, or fallback. The model definition must allow the downstream Solving stage to perform API translation only, without redesigning the solving strategy.
