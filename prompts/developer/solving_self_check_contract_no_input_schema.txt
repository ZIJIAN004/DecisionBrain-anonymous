[ENVIRONMENT] The workspace is the current cwd; the shell limit is approximately __TIME_BUDGET__ seconds, and the solver's internal time limit must be shorter.

[REQUIRED ARTIFACTS]
- from_data_to_input.py: a reproducible conversion program that reads the real `data/` and deterministically generates input.json through JSON parsing and structured mapping; it must be retained after completion.
- input.json: normalized input conforming to the input structure that you determine from `data/` yourself (no input schema is provided in this run), generated only through one separate `python3 from_data_to_input.py` shell call.
- solver.py: reads the real data, invokes the selected algorithm, generates and self-checks the result, and is executed by Runtime's `run_solver`.
- solution.json: the complete business-semantic solution conforming to solution_schema.json, generated only by executing solver.py through `run_solver`.
- feasibility_result.json: produced by calling feasibility_checker.py.
- solver_result.json: detailed solve summary.
- stage_outputs/solving.json: stores only the stage decision and a reference to solver_result.json.
