# Problem Description

A hospital must create a roster that assigns nurses to shifts over a planning horizon consisting of a whole number of weeks, where all weeks start on Monday. The entities involved are a set of nurses, a set of days spanning the planning horizon, a set of shift types (such as early, late, or night shifts each with a known duration in minutes), and a set of weekends (each weekend comprising the Saturday and Sunday of its respective week). The input data specifies, for each shift type, its length in minutes and the set of other shift types that may not immediately follow it on the next day (forbidden successor shifts). For each nurse, the data provides the maximum number of shifts of each type that nurse may work over the horizon, the minimum and maximum total working time in minutes over the horizon, the minimum and maximum number of consecutive shifts the nurse may work in any unbroken stretch of working days, the minimum number of consecutive days off the nurse may take in any unbroken stretch of off-days, the maximum number of weekends the nurse may work, and a set of specific days on which the nurse must not be assigned any shift. The data also includes shift-on requests and shift-off requests: a shift-on request specifies a penalty incurred if a particular nurse is not assigned a particular shift type on a particular day, and a shift-off request specifies a penalty incurred if a particular nurse is assigned a particular shift type on a particular day. Finally, for each combination of day and shift type, the data gives a preferred number of nurses to be assigned, together with an under-coverage weight and an over-coverage weight.

The hospital must decide, for each nurse on each day, which shift type (if any) to assign. Each nurse may work at most one shift on any given day. On any two consecutive days, a nurse may not be assigned a shift type on the first day followed by a forbidden successor shift type on the second day; for purposes of this rule, the last day of the previous planning period and the first day of the next planning period are treated as days off. Over the entire horizon, no nurse may be assigned more shifts of any given type than that nurse's per-type maximum. The total working time for each nurse, computed as the sum of the durations of all assigned shifts, must fall between that nurse's minimum and maximum total minutes. In any window of consecutive days whose length equals one more than a nurse's maximum consecutive shifts, the number of shifts assigned to that nurse must not exceed the maximum; for this rule, the day before the horizon and the day after the horizon are treated as days off. A nurse must never work an isolated block of consecutive shifts shorter than the nurse's minimum consecutive shifts requirement; formally, if a nurse is off on some day and also off on a day that is only a short gap later (where the gap length is less than the minimum), then the nurse cannot be working on all of the days in between without also working on at least one of those boundary days. The same logic applies symmetrically at the boundaries of the planning horizon, where it is assumed that the nurse has been working an infinite stretch of consecutive shifts just before the first day and just after the last day. An analogous rule governs consecutive days off: a nurse must never have an isolated block of consecutive days off shorter than the nurse's minimum consecutive days off, and at the horizon boundaries it is assumed the nurse has been off for an infinite stretch. A weekend is considered worked if the nurse is assigned any shift on either the Saturday or the Sunday of that weekend, and the total number of worked weekends for each nurse must not exceed that nurse's maximum. On each day in the nurse's set of requested days off, the nurse must not be assigned any shift.

The penalty for each nurse-day-shift combination arising from shift-on and shift-off requests is captured as follows: if a shift-on request exists with a given penalty and the nurse is not assigned that shift, the penalty is incurred; if a shift-off request exists with a given penalty and the nurse is assigned that shift, the penalty is incurred. For staffing coverage, the number of nurses assigned to each shift type on each day may differ from the preferred number; the amount by which actual staffing falls below the preferred level and the amount by which it exceeds the preferred level are each recorded separately. The goal is to minimize the total penalty, which is the sum of all shift-on/off request penalties across all nurses, days, and shift types, plus the sum over all days and shift types of the under-coverage amount multiplied by its under-coverage weight, plus the sum over all days and shift types of the over-coverage amount multiplied by its over-coverage weight.


## Additional binding constraint
In addition to all requirements above, on day 0, shift type 0 must be assigned to at least 51 distinct nurses.
