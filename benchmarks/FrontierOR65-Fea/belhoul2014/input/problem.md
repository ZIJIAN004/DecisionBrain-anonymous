# Problem Description

A company must assign n tasks to n agents on a one-to-one basis, so that every task is performed by exactly one agent and every agent performs exactly one task. There are p distinct performance criteria, and for each criterion the cost of assigning any particular task to any particular agent is a given non-negative integer. The input therefore specifies the number of tasks and agents (n), the number of criteria (p), one n-by-n cost matrix per criterion, a reference point consisting of one real-valued target per criterion, and a search direction consisting of one strictly positive weight per criterion.

For a given assignment, the total cost under each criterion is the sum of the individual assignment costs for that criterion across all task-agent pairs that are selected. The goal is to find the assignment that best compromises among the p criteria, where the quality of a compromise is measured as follows: for each criterion, compute the product of its search-direction weight and the difference between the assignment's total cost on that criterion and the corresponding reference-point value, then take the maximum of these p products. The assignment to be found is the one that minimizes this worst-case weighted deviation.

To express this as a single problem, an auxiliary value representing the worst-case weighted deviation is introduced. This value is unrestricted in sign and must be at least as large as, for every criterion, the product of that criterion's search-direction weight and the difference between the assignment's total cost on that criterion and the reference-point value for that criterion. Each task must be assigned to exactly one agent, and each agent must be assigned exactly one task. The goal is to minimize the worst-case weighted deviation value.
