# Problem Description

A job shop contains a set of jobs and a set of machines. Each job consists of exactly as many operations as there are machines, with each operation assigned to a distinct machine, so that every job visits every machine exactly once. The order in which a job visits the machines is prescribed and may differ from job to job; this sequence is called the job's technological sequence. Each operation has a known processing time that depends on both the job and the machine. Every job has a release date (the earliest time its first operation may begin), a due date (the target completion time), and a positive weight reflecting the job's priority.

The input data for an instance specifies the number of jobs, the number of machines, and, for every job, its weight, release date, due date, and the ordered list of operations with their respective machines and processing times.

The scheduler must determine, for every operation, when it starts processing. Equivalently, for every machine the scheduler must fix the order in which the jobs assigned to that machine are processed. A schedule is valid when four conditions hold simultaneously. First, the first operation of a job may not start before that job's release date. Second, the operations of each job must be processed in the prescribed technological order: the next operation of a job cannot start until the preceding operation of the same job has finished, where finishing means the start time plus the processing time. Third, each machine can process at most one operation at a time, so for every pair of operations sharing a machine one must finish entirely before the other begins. Fourth, the completion time of a job equals the start time of its last operation plus that operation's processing time, and the tardiness of a job is the amount by which its completion time exceeds its due date, or zero if the job finishes on time or early.

The goal is to find a valid schedule that minimizes the total weighted tardiness, which is the sum over all jobs of each job's weight multiplied by its tardiness.
