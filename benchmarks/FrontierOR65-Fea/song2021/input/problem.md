# Problem Description

A company must schedule the execution of a set of orders over a discrete planning horizon divided into a given number of time periods. Each period has a known regular workforce capacity measured in man-hours. Each order has a known work content (in man-hours), a release date (the earliest period in which work on the order may begin), a due date (the target completion period), and a per-period tardiness penalty cost. A single global unit cost applies to all nonregular (overtime) capacity used in any period.

The company must decide, for each order and each time period, the execution intensity of that order in that period, expressed as the fraction of the order's total work content performed during that period. Each order must be executed without preemption: it is worked on during a contiguous block of consecutive periods, starting in exactly one period and finishing in exactly one period, with the finish period no earlier than the start period. The start period must be no earlier than the order's release date. The sum of the intensity fractions assigned to each order across all periods must equal one, meaning that the order's entire work content is completed exactly once. In any period during which an order is being executed (that is, in any period from its start through its finish), the intensity must lie between a given order-specific lower bound and a given order-specific upper bound, where the lower bound is strictly greater than zero and the upper bound is at most one. In periods outside an order's execution window, its intensity is zero.

For each order, the start period and finish period together define an execution interval, and the schedule must select exactly one execution interval per order from the set of feasible execution intervals for that order. An execution interval is feasible only if its start period is no earlier than the order's release date, its finish period is no later than the end of the planning horizon, and its length (the number of periods from the start period through the finish period, inclusive) is compatible with the order's intensity bounds: the length must be at least the ceiling of one divided by the order's upper intensity bound and at most the floor of one divided by the order's lower intensity bound, since the per-period intensity bounds together with the requirement that the intensities sum to one impose these limits on how many periods the order can occupy.

For each period, the total resource consumption equals the sum over all orders of each order's intensity in that period multiplied by its work content. Whenever this total exceeds the regular capacity available in that period, the excess is covered by nonregular capacity. Each order's tardiness equals the amount by which its finish period exceeds its due date, or zero if it finishes on time or early.

The goal is to minimize the total cost, which is the sum of two components: the total weighted tardiness, computed as the sum over all orders of each order's tardiness penalty multiplied by its tardiness, and the total nonregular capacity cost, computed as the unit cost of nonregular capacity multiplied by the sum of nonregular capacity used across all periods.
