# Problem Description

Consider a set of entities that must be assigned one-to-one to an equal number of positions, forming a perfect one-to-one matching. Three square matrices of numerical data are given, each having as many rows and columns as there are entities: a first cost matrix A, a second cost matrix B, and a linear cost matrix C. Each entry of A, B, or C corresponds to a specific entity-position pair. The entry of A for a given entity and position represents the cost contribution from matrix A when that entity is assigned to that position, and likewise for B and C. The assignment is encoded by choosing, for each entity, exactly one position, such that every position is occupied by exactly one entity.

The total cost of an assignment has a multiplicative-plus-linear structure. Specifically, the total cost equals the product of two sums plus a third sum: the sum over all assigned entity-position pairs of the corresponding A entries is multiplied by the sum over all assigned entity-position pairs of the corresponding B entries, and to this product is added the sum over all assigned entity-position pairs of the corresponding C entries. In other words, if one computes a single aggregate A-cost by summing the A entry for every matched entity-position pair, and similarly a single aggregate B-cost and a single aggregate C-cost, then the total cost is the aggregate A-cost times the aggregate B-cost plus the aggregate C-cost.

The goal is to find the one-to-one assignment of entities to positions that minimizes this total cost. Each entity must be assigned to exactly one position and each position must receive exactly one entity, so the assignment forms a permutation of the positions.
