# Problem Description

An investor selects a portfolio from a universe of N assets. The investor must allocate wealth across these assets by choosing a fractional weight for each asset, where all weights sum to one and no weight is negative (short selling is prohibited). For each asset, the investor also makes a yes-or-no inclusion decision. To limit monitoring and transaction costs, the investor may include at most k assets; any asset not included must receive zero weight.

The input data specifies the number of assets N, a cardinality limit k on how many assets may be held, a CVaR probability level beta (a value strictly between zero and one, typically set to 0.9), and an ell-2 regularization parameter gamma (a positive scalar). For each asset, an expected return is provided, collected into a vector of length N. A required return level mu_bar is given, and the portfolio's expected return (the sum of each asset's weight times its expected return) must be at least mu_bar. Additionally, a set of S return scenarios is provided, where each scenario contains a return value for every asset. Each scenario has an associated occurrence probability p_s; in the standard setting all scenarios are equally likely with probability one over S.

The goal is to minimize the sum of three terms: a regularization term equal to one over twice gamma times the sum of squared portfolio weights, a value a that may be any real number and represents the value-at-risk threshold, and a value v that must be zero or greater and represents the tail-risk contribution beyond the threshold. The value v must be at least as large as one over one minus beta times the probability-weighted sum, across all scenarios, of the amount by which the scenario loss exceeds a, or zero if the scenario loss does not exceed a. The scenario loss for a given scenario is the negative of the sum of each asset's scenario return multiplied by its portfolio weight. Equivalently, for each scenario, one computes the negative portfolio return under that scenario minus a, takes the larger of this value and zero, multiplies by the scenario probability, sums over all scenarios, divides by one minus beta, and requires v to be no smaller than the result.

If an asset is not included (that is, if the investor's inclusion decision for that asset is no), then its portfolio weight must be zero. The total number of included assets must not exceed k. Beyond the budget and nonnegativity requirements, the only linear inequality imposed on the portfolio weights is the expected-return requirement described above (namely, the portfolio's expected return must be at least mu_bar); no further linear inequalities are imposed. The portfolio weights must all be nonnegative and must sum to exactly one.
