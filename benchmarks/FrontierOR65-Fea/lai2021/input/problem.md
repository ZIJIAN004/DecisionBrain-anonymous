# Problem Description

A collection of N elements is given, together with a symmetric distance measure between every pair of distinct elements, yielding N times (N minus one) divided by two pairwise distances, all of which are nonnegative. The elements must be partitioned into exactly m groups. Each of the m groups has a specified lower capacity limit and an upper capacity limit on the number of elements it may contain. Every element must be placed in exactly one group, and the number of elements assigned to any group must fall between that group's lower and upper capacity limits, inclusive. The goal is to assign all elements to groups so as to maximize the total diversity, defined as the sum, over all groups, of the pairwise distances between every pair of elements that belong to the same group. Equivalently, for each group, every pair of co-assigned elements contributes their pairwise distance to the objective, and the objective is the grand total of all such within-group pairwise distances across all groups.

The input data consists of the total number of elements N, the number of groups m, a lower capacity limit and an upper capacity limit for each of the m groups, and the pairwise distance between every pair of distinct elements stored as the upper triangle of a symmetric distance matrix in row-major order.
