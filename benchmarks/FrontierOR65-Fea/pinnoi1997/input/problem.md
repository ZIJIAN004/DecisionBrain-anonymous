# Problem Description

An assembly line consists of a set of tasks and a fixed number of workstations arranged in series. Each task has a known integer processing time. The tasks are related by a precedence graph that specifies immediate predecessor relationships: if one task is an immediate predecessor of another, then the predecessor must be processed at a station whose number is no greater than the station number assigned to the successor. The line operates with a fixed cycle time, which is the maximum allowable total processing time at any single station. The number of stations is given as a fixed input parameter representing the optimal (minimum feasible) number of stations for the line.

The input data specifies the number of tasks, the processing time of each task, the cycle time, the number of stations, the set of immediate precedence arcs between tasks, and for each task the earliest and latest station to which it may feasibly be assigned. These earliest and latest station bounds are derived from the precedence structure and processing times: the earliest station for a task is determined by the cumulative processing time of the task itself together with all of its predecessors, divided by the cycle time and rounded up, while the latest station is determined by subtracting from the total number of stations the cumulative processing time of the task itself together with all of its successors, divided by the cycle time and rounded up, plus one.

The planner must assign every task to exactly one station, choosing from among the stations between its earliest and latest feasible station inclusive. The assignment must respect all precedence relationships: for every immediate precedence arc, the station number assigned to the predecessor task must not exceed the station number assigned to the successor task. The total processing time of all tasks assigned to any single station must not exceed the cycle time. In addition, the planner must determine a single value representing the worst-case station idle time across the entire line.

The idle time at a station is the difference between the cycle time and the total processing time of the tasks assigned to that station. The worst-case idle time value must be at least as large as the idle time at every station, meaning that for each station, the sum of the processing times of tasks assigned to it plus this worst-case value must be at least equal to the cycle time. A lower bound on this worst-case value is given by the floor of the quantity obtained by dividing the total slack across all stations (the number of stations times the cycle time minus the sum of all task processing times) by the cycle time.

The goal is to minimize this worst-case station idle time, thereby producing the most balanced distribution of work across the stations on the line.
