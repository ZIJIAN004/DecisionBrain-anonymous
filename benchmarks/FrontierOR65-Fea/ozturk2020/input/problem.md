# Problem Description

A facility operates M identical parallel batch-processing machines, each with the same capacity Cap. There are N jobs to be processed, and each job has three attributes: a release date (the earliest time at which the job becomes available for processing), a processing time, and a size (an integer quantity representing how much of a machine's capacity the job consumes). Jobs must be grouped into batches and each batch is assigned to exactly one machine. Every job must appear in exactly one batch on exactly one machine. The total size of all jobs assigned to a given batch must not exceed Cap. All jobs in the same batch are processed simultaneously: the batch begins processing at a single start time and runs for a single duration, after which every job in that batch is complete. The processing duration of a batch equals the longest processing time among the jobs it contains; specifically, the batch duration must be at least as large as the processing time of every job assigned to that batch. The start time of a batch must be no earlier than the release date of every job assigned to that batch, ensuring that no job is processed before it becomes available. On each machine, batches are processed sequentially in a fixed order indexed from one up to at most N (since at most N batches can exist). For every pair of consecutively indexed batches on the same machine, the later batch cannot start before the earlier batch has finished, meaning the start time of each batch is at least the start time of the preceding batch on that machine plus the preceding batch's processing duration. The completion time of each job equals the finish time of the batch it belongs to, that is, the start time of that batch plus the batch's processing duration. The goal is to minimize the total flow time, defined as the sum of completion times across all N jobs.
