# Problem Description

A telecommunications or logistics company operates over a directed network of nodes connected by potential arcs. The network consists of a given number of nodes and a given set of directed arcs, where each arc leads from one specific node to another. A set of commodities must be shipped through this network, each commodity defined by an origin node, a destination node, and a demand quantity representing the total amount of flow that must be sent from the origin to the destination. The company must decide which arcs to install and how to route each commodity's flow through the installed arcs.

Each arc has a fixed installation cost that is incurred once if the arc is used by any commodity. In addition, each arc has a per-unit transportation cost that depends on the specific commodity being routed, so the cost of sending one unit of a given commodity along a given arc may differ from the cost for a different commodity on the same arc. The actual transportation cost for routing a commodity along an arc equals the commodity's demand quantity multiplied by its per-unit cost on that arc multiplied by the fraction of the commodity's demand assigned to that arc.

Flow must be conserved at every node for every commodity. Specifically, for each commodity, the total fractional flow entering a node minus the total fractional flow leaving that node must equal negative one at the commodity's origin (indicating that one full unit of fractional flow is produced there), positive one at the commodity's destination (indicating that one full unit of fractional flow is consumed there), and zero at every other node. No commodity may send any flow along an arc that has not been installed. There are no capacity limits on the arcs, meaning an installed arc can carry any amount of flow from any number of commodities.

The goal is to minimize the total cost, which is the sum of the fixed installation costs of all arcs chosen to be installed plus the total transportation costs across all commodities and all arcs. The transportation cost component sums, over every commodity and every arc, the product of the commodity's demand, its per-unit arc cost, and the fraction of that commodity's demand routed on that arc.
