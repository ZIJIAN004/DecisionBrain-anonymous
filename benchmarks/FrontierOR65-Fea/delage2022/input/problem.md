# Problem Description

A steel tube manufacturer operates an open-ended cutting machine that slices a continuous steel tube into smaller pieces of various product types. The machine has a fixed length, and it is configured using cutting patterns, each of which specifies how many pieces of each product type are cut simultaneously in a single pass. The machine may use multiple distinct patterns, and each pattern may be repeated multiple times. Because the machine is open-ended (the tube extends beyond the machine on one side), each repetition of any pattern can additionally produce one extra piece of any product type beyond what the pattern itself specifies.

The input data consists of a set of products and a set of available patterns. Each product has a known length and a known demand (the number of pieces required). The cutting machine has a known total length. Two time-cost parameters are given: a setup time incurred once for each pattern that is used, and a cutting time incurred once per repetition of any pattern. A large number, equal to the maximum demand among all products, caps the number of repetitions any single pattern may have. For each product, the maximum number of pieces of that product that can fit within a single pattern is also given (computed as the machine length divided by the product length, rounded down).

The manufacturer must decide which patterns to use, how many pieces of each product type to include in each pattern, how many times to repeat each pattern, and how many extra pieces of each product type to produce. The total number of units of each product produced by a given pattern equals the number of pieces of that product specified in that pattern multiplied by the number of repetitions of that pattern. If a pattern is not used, no pieces may be assigned to it. If a pattern is used, the sum of the lengths of all pieces assigned to it must not exceed the machine length. A pattern may have repetitions only if it has been set up for use, and its repetition count is limited by the large number described above. For every product, the total production from all patterns plus the extra pieces must meet or exceed the product's demand. The total number of extra pieces produced across all products must not exceed the total number of pattern repetitions across all patterns, reflecting the physical rule that at most one extra piece can be obtained per repetition. To avoid interchangeable orderings among patterns, patterns are ordered so that the number of repetitions of each pattern is at least as large as the number of repetitions of the next pattern. The number of pieces of each product in each pattern must be a whole number of zero or more, and the number of repetitions of each pattern must also be a whole number of zero or more. The number of extra pieces of each product must be zero or more.

The goal is to minimize the total time, computed as the sum of the setup times for all used patterns plus the sum of the cutting times for all pattern repetitions.
