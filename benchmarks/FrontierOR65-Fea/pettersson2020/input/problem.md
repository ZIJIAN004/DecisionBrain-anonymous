# Problem Description

A collection of items is available for selection, where each item either is or is not included. The number of items and the number of objectives are given as input. Each item has a known integer weight, and there is a single knapsack with a known integer capacity. Each objective is defined by a vector of integer coefficients, one per item, and the value of that objective for a given selection equals the sum of the coefficients of the selected items. The total weight of all selected items must not exceed the knapsack capacity.

All objectives are to be simultaneously minimized. Because the objectives generally conflict, no single selection of items will minimize every objective at once. Instead, the goal is to identify the complete set of non-dominated objective vectors. An objective vector is the tuple of objective values produced by a particular selection of items. One objective vector dominates another if it is at least as good (no greater) on every objective and strictly better (strictly less) on at least one objective. A non-dominated objective vector is one that is not dominated by any other achievable objective vector. The task is to enumerate every non-dominated objective vector, along with a corresponding item selection that satisfies the capacity limit and produces it.

The input data for an instance specifies the number of items, the number of objectives, the integer weight of each item, the integer knapsack capacity, and for each objective the integer coefficient associated with every item. Weights and coefficients are drawn from the range sixty through one hundred inclusive, and the capacity equals the integer part of half the sum of all item weights.
