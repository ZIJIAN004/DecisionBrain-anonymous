# Problem Description

A container terminal operates a single storage block served by two identical rail-mounted gantry cranes that share the same pair of rails. The block is modeled as a one-dimensional line of positions called slots, numbered from zero through a value equal to the number of storage slots plus one. Slot zero is the seaside handover point where inbound containers arrive, and the last slot is the landside handover point where outbound containers must be delivered. The slots in between are storage positions. One crane, called the seaside crane, is responsible for handling containers that arrive from the seaside, while the other, called the landside crane, handles both seaside containers that require cooperative processing and landside containers that must leave through the landside handover point. Time is discretized into unit-length intervals, and in each interval a crane performs exactly one operation: move one slot to the left, move one slot to the right, lift part of a container pickup, drop part of a container placement, or wait in place. Lifting and dropping each take a fixed number of consecutive time units, the same for both cranes, during which the crane remains stationary at the relevant slot.

The input specifies the number of storage slots, the number of seaside containers, the number of landside containers, and the number of time units required for each lift or drop operation. Each crane has a given initial slot position, and the seaside crane must always be strictly to the left of the landside crane. There are n seaside containers arriving at slot zero in a fixed pickup sequence: container one must be picked up before container two, and so on. Each seaside container has a designated target storage slot, which may be any slot from one through the last slot. There are m landside containers, each already stored at a known source slot among the interior storage positions. Each landside container has an earliest finish time, representing the earliest time at which it may be dropped at the landside handover point, and a deadline, representing the latest time by which it must be dropped there. The landside containers are ordered by non-decreasing deadline.

The scheduler must determine the position and operation of each crane at every time step from time zero up to an upper bound on the time horizon. The seaside crane picks up seaside containers at slot zero in their prescribed order and moves each one toward its target slot or toward an intermediate handover slot. Either the seaside crane delivers a seaside container all the way to its target slot, or the seaside crane drops the container at an intermediate storage slot and the landside crane later picks it up from that same slot and delivers it to the target slot. Each seaside container is handled at most once by each crane, meaning the seaside crane performs exactly one lift and one drop per container, and if the landside crane is involved it also performs exactly one lift and one drop for that container. Landside containers are handled exclusively by the landside crane, which picks each one up from its source slot and drops it at the landside handover point.

The two cranes travel on the same rails and can never occupy the same slot at the same time; the seaside crane must remain at least one slot to the left of the landside crane at every time instant. Both cranes must stay within the bounds of the block. Each crane can carry at most one container at a time, so lifts and drops alternate for each crane. Whenever a crane is lifting a container, it must remain at the origin slot of that container for the full duration of the lift, and whenever it is dropping a container, it must remain at the destination slot for the full duration of the drop. The landside crane cannot begin lifting a new container while it is still in the middle of dropping another one.

If the landside crane picks up a seaside container from an intermediate slot, that slot must be the same slot where the seaside crane previously dropped it, and the landside crane's lift may only begin after the seaside crane's drop has started at that slot. The landside crane can only begin dropping a seaside container at its target slot after it has finished lifting that container from its intermediate slot, and similarly can only begin dropping a landside container at the landside handover point after lifting it from its source slot. The seaside crane must drop its containers respecting the original pickup sequence: earlier containers in the sequence must be dropped no later than later containers.

Regarding which landside containers must be served: every landside container whose deadline is no later than the final makespan must be processed. In addition, to avoid infeasibility just beyond the end of the planning horizon, if there are landside containers not yet due by the makespan, at least one landside container from the group sharing the next-earliest deadline after the makespan must also be processed. Whenever a landside container is processed, it must be dropped at the landside handover point at a time that lies within the window between its earliest finish time and its deadline.

The goal is to minimize the makespan of seaside container processing, defined as the earliest time by which all seaside containers have been dropped at their target slots.
