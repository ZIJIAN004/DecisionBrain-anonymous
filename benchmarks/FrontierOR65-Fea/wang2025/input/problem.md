# Problem Description

A planner is given a ground set of n elements, indexed from one to n, and must select a subset of at most k elements to maximize the value of a non-decreasing approximately submodular set function f. The function f maps every subset of the ground set to a real number, returns zero for the empty set, and is evaluated through an oracle that depends on the instance type. Three types of instances define f differently, each involving m auxiliary entities (clients, items, or targets, where m equals n plus one) and an m-by-n data matrix.

In a Facility Location (LOC) instance, the m entities are clients and the n elements are candidate facility sites. Each entry of the data matrix gives the benefit that a given client receives from a given facility, a nonnegative value. The value of a selected subset is the sum over all clients of the maximum benefit that each client obtains from any facility in the subset.

In a Weighted Coverage (COV) instance, the m entities are items and the n elements are sensors. Each entry of the data matrix is either zero or one, indicating whether a given sensor covers a given item. Each item also carries a nonnegative weight. The value of a selected subset of sensors is the sum over all items of that item's weight times the maximum coverage indicator across all selected sensors, which equals the item's weight if at least one selected sensor covers it and zero otherwise.

In a Bipartite Influence (INF) instance, the m entities are targets and the n elements are influence sources. A bipartite graph connects targets to sources: each entry of the data matrix is zero or one, recording whether an edge exists from a given target to a given source. Each source has an activation probability between zero and one. For a given target and source, the influence probability is that source's activation probability if the edge exists and zero otherwise. The value of a selected subset of sources is the sum over all targets of the probability that the target is reached by at least one selected source, computed as one minus the product over all selected sources of one minus the corresponding influence probability.

Each instance also provides a parameter called gamma bar, a value greater than zero and at most one, which serves as a computable upper bound on the submodular ratio of f. The submodular ratio measures how close f is to being exactly submodular: it is defined as the minimum, taken over all pairs of subsets A and B of the ground set for which the denominator is nonzero, of the ratio of f applied to A minus f applied to the intersection of A and B, divided by f applied to the union of A and B minus f applied to B, with the convention that zero divided by zero equals one. The parameter gamma bar is an upper bound on this ratio, defined as the minimum over all subsets of the ground set and all elements not belonging to the union of that subset with another element, of the ratio of the marginal gain of adding that element to the subset divided by the marginal gain of adding that element to the subset together with the other element, where the marginal gain of adding an element to a given set means f applied to the union of that set and that element minus f applied to that set.
