# Problem Description

A fleet of shared autonomous vehicles (SAVs) operates on a directed traffic network consisting of nodes and links. Nodes are partitioned into junctions, which represent road intersections, and centroids, which represent zones where travelers originate, arrive, and where vehicles may park. Each centroid is connected to the road network through special centroid connector links. The analysis covers a discrete time horizon from time step zero through the final time step, with each time step representing one unit of time.

Each directed road link has a known length, free-flow speed, congested wave speed, and flow capacity. The ratio of length to free-flow speed for every link is a positive integer giving the free-flow travel time in time steps. A jam density parameter, common across the network, determines the maximum number of vehicles that can physically occupy any link, equal to the jam density multiplied by the link length. Centroid connectors have a free-flow travel time of exactly one time step and effectively unlimited capacity. The network is assumed empty at the start of the analysis period, meaning no vehicles are in transit on any link at time zero.

A known number of vehicles are parked at each centroid at the start of the analysis. Person-trip demand is specified for each origin-destination centroid pair at each time step, giving the number of travelers wishing to depart from a given origin to a given destination at that time. Each vehicle serves exactly one traveler at a time with no ride-sharing. All vehicular travel in the network is by SAVs; there are no personal vehicles. Because the number of vehicles is large, all vehicle flows and traveler quantities are treated as continuous quantities rather than whole numbers.

The planner must determine, for every time step and every link, how many vehicles destined for each centroid turn from that link onto each successor link. The planner must also determine how many vehicles depart each centroid via each outgoing centroid connector toward each destination at each time step, how many travelers are picked up at each origin for each destination at each time step, and how many travelers remain waiting at each origin for each destination at each time step. The number of vehicles parked at each centroid at each time step is also determined. All vehicle flow quantities, traveler pickup counts, parked vehicle counts, and waiting traveler counts must be zero or positive.

Traffic flow on road links is governed by the link transmission model, which tracks cumulative vehicle counts at the upstream and downstream ends of each link, disaggregated by destination. At time zero, all upstream and downstream cumulative counts on every link are zero. For each road link and each outgoing centroid connector, the upstream cumulative count for a given destination at the next time step equals the current upstream count plus the total turning flow of vehicles with that destination from that link onto all of its successor links at the current time step. For each road link and each incoming centroid connector, the downstream cumulative count for a given destination at the next time step equals the current downstream count plus the total turning flow of vehicles with that destination from all predecessor links onto that link at the current time step.

No vehicle flow may exit a link before the free-flow travel time has elapsed; turning flows on any link are zero for all time steps strictly before the free-flow travel time of that link. For each destination separately, the total turning flow of vehicles with that destination from a road link or outgoing centroid connector onto successor links at a given time step is bounded by the sending flow for that destination on that link. The sending flow for a given destination on a link equals the upstream cumulative count for that destination evaluated at a time equal to the current time step minus the free-flow travel time of the link plus one, minus the downstream cumulative count for that destination at the current time step. On road links only, the total outgoing flow of vehicles of all destinations at any time step may not exceed the link capacity. Similarly, on road links only, the total incoming flow of vehicles of all destinations turning onto that link at any time step may not exceed the link capacity. Additionally, on road links, the total incoming flow is limited by a congested-wave bound: the sum of all incoming turning flows may not exceed the sum over all destinations of the difference between the upstream cumulative count evaluated at a time equal to the current time step minus the ratio of link length to congested wave speed plus one and the downstream cumulative count at the current time step, plus the maximum vehicle occupancy of that link.

For incoming centroid connectors, the downstream cumulative count for each destination at the next time step simply equals the upstream cumulative count at the current time step. Vehicles cannot pass through an incoming centroid connector unless their destination matches the centroid at which that connector terminates; turning flows on incoming centroid connectors are zero whenever the vehicle destination differs from the connector's terminal centroid.

The number of vehicles parked at a centroid at the next time step equals the current parked count plus the number of vehicles arriving at that centroid via incoming centroid connectors (measured as the difference between upstream and downstream cumulative counts for vehicles destined for that centroid) minus the total number of vehicles departing that centroid via outgoing centroid connectors toward all destinations. The total number of vehicles departing a centroid across all outgoing connectors and all destinations at any time step cannot exceed the number of vehicles currently parked there. The upstream cumulative count on an outgoing centroid connector for a given destination at the next time step equals the current count plus the number of vehicles departing the centroid along that connector toward that destination. The total number of vehicles parked across all centroids at the final time step must equal the total number parked across all centroids at time zero.

Unserviced traveler demand waiting at each origin for each destination evolves over time: the waiting count at the next time step equals the current waiting count plus newly arriving demand minus travelers picked up at that time step. The number of travelers picked up at an origin for a given destination at any time step cannot exceed the number of travelers currently waiting there for that destination, and it also cannot exceed the total number of vehicles departing that origin toward that destination at that time step. By the end of the time horizon, all waiting demand must have been served, so the unserviced count for every origin-destination pair at the final time step must be zero.

The goal is to minimize the total system travel time, defined as the sum of two components: the total vehicle-time spent on links, computed by summing over all links, all destinations, and all time steps the difference between the upstream and downstream cumulative counts, plus the total traveler waiting time, computed by summing over all origin-destination pairs and all time steps the unserviced waiting demand.
