# Problem Description

A project consists of a set of real activities numbered from 1 through n, plus two placeholder activities numbered 0 and n+1 that represent the project start and the project end, respectively. These placeholder activities have zero processing time. Each real activity has a given processing time expressed as a whole number of time periods and cannot be interrupted once started. The project is subject to a prescribed deadline by which the end activity must be completed.

Pairs of activities are linked by temporal constraints, each specified as a directed arc from one activity to another together with a time lag value that is a whole number (which may be negative, zero, or positive). Each temporal constraint requires that the start time of the activity at the head of the arc is at least the lag value time units after the start time of the activity at the tail of the arc. When the lag value is zero or positive, this enforces a minimum start-to-start delay between the two activities. A maximum time lag from one activity to another is represented by a reverse arc from the second activity back to the first, carrying a negative lag value. Applying the same rule to this reverse arc ensures that the second activity's start time exceeds the first activity's start time by no more than the absolute value of that negative lag. The project start activity must begin at time zero, and all activity start times must be whole numbers.

The project is also subject to a set of partially renewable resources. Each partially renewable resource is defined by three pieces of given data: a capacity expressed as a whole number (zero or greater), a per-activity demand for every activity expressed as a whole number (zero or greater), and a designated subset of time periods drawn from the planning horizon (the integers from 1 through the project deadline). An activity's resource usage for a given partially renewable resource counts how many of that resource's designated time periods fall within the activity's execution interval, where the execution interval of an activity consists of the time periods strictly greater than its start time up to and including its start time plus its processing time. The resource consumption of an activity for a given resource equals the product of the activity's resource usage and the activity's per-activity demand for that resource. For each partially renewable resource, the total resource consumption summed over all activities must not exceed the resource's capacity.

The goal is to determine a whole-number start time for every activity such that all temporal constraints are satisfied, the project start activity begins at time zero, the project end activity starts no later than the deadline, and no partially renewable resource capacity is exceeded, while minimizing the start time of the project end activity, which equals the overall project duration.
